## 1. `FastViTHD` 与主流视觉编码器架构参数对比

### 1.1 `FastViTHD` 5 阶段逐层结构表（Sec. 3.2 & 附录 B）

| 阶段 / 模块 | 算子类型 | 下采样层（进入该阶段前） | 累计空间下采样倍数 | 输入为 $R \times R$ 时的特征图尺寸 | 块数量（Depth） | 通道维度（Embed Dim） | MLP 扩展比（ConvFFN） |
| :--- | :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| **Stem** | Convolutional Stem | 长宽各 $4\times$ 下采样 | $4\times$ | $\frac{R}{4} \times \frac{R}{4}$ | - | 96 | - |
| **Stage 1** | `RepMixer` + `ConvFFN` | 承接 Stem | $4\times$ | $\frac{R}{4} \times \frac{R}{4}$ | 2 | 96 | 4.0 |
| **Stage 2** | `RepMixer` + `ConvFFN` | $7\times 7$ DWConv (stride=2) + $1\times 1$ PWConv | $8\times$ | $\frac{R}{8} \times \frac{R}{8}$ | 12 | 192 | 4.0 |
| **Stage 3** | `RepMixer` + `ConvFFN` | $7\times 7$ DWConv (stride=2) + $1\times 1$ PWConv | $16\times$ | $\frac{R}{16} \times \frac{R}{16}$ | 24 | 384 | 4.0 |
| **Stage 4** | `MHSA` (多头自注意力) + `ConvFFN` | $7\times 7$ DWConv (stride=2) + $1\times 1$ PWConv | $32\times$ | $\frac{R}{32} \times \frac{R}{32}$ | 4 | 768 | 4.0 |
| **Stage 5** | `MHSA` (多头自注意力) + `ConvFFN` | $7\times 7$ DWConv (stride=2) + $1\times 1$ PWConv | **$64\times$** | $\frac{R}{64} \times \frac{R}{64}$ | 2 | 1536 | 4.0 |
| **Multi-Scale Fusion (`C`)** | 2D DWConv Learned Pool + 通道拼接 | 将多阶段特征对齐到 $\frac{R}{64} \times \frac{R}{64}$ | **$64\times$** | $N_v = \left(\frac{R}{64}\right)^2$ 个视觉 Token | - | 拼接后经 Connector 投影 | - |

> **关键设计细节**：
> 1. **无 Squeeze-and-Excitation (SE)**：相比 MobileCLIP 的 `FastViT-MCi2`（含 SE 层且 MLP 扩展比为 3.0），`FastViTHD` 去掉了高分辨率下拖慢推理的 SE 层，并将 ConvFFN 扩展比提升至 4.0。
> 2. **对比 `FastViT-Naive Scaling`（附录 B.1）**：朴素放大版采用 4 阶段设计，深度为 `[2, 12, 16, 6]`，通道维度为 `[128, 256, 512, 1024]`，总下采样率仅 $32\times$（即 Stage 3 在 $16\times$ 下采样上跑 16 层，Stage 4 在 $32\times$ 下采样上跑 6 层 MHSA + SE），在相同 125.1M 参数量下高分辨率延迟远高于 `FastViTHD`（见论文 Fig. 3）。

### 1.2 不同视觉编码器的 Token 数生成公式与具体数值对比

对于输入分辨率 $R \times R$：
- **ViT-L/14**（Patch Size = 14，各向同性）：$N_v = (R / 14)^2$
- **SigLIP-SO400M**（Patch Size = 14，各向同性）：$N_v = (R / 14)^2$
- **FastViT (MCi2)** / **ConvNeXt**（4 阶段，总下采样率 $32\times$）：$N_v = (R / 32)^2$
- **FastViTHD (Ours)**（5 阶段，总下采样率 $64\times$）：$N_v = (R / 64)^2$

| 输入分辨率 $R \times R$ | ViT-L/14 ($p=14$) | FastViT / ConvNeXt ($32\times$) | **FastViTHD ($64\times$)** | FastViTHD 相比 ViT-L/14 缩减倍数 |
| :---: | :---: | :---: | :---: | :---: |
| $224 \times 224$ | 256 | 49 | - (预训练分辨率) | $\sim 16\times$ |
| $256 \times 256$ | $\sim 334$ | 64 | **16** | **$20.9\times$** |
| $336 \times 336$ | **576** | $\sim 110$ | - | - |
| $512 \times 512$ | $\sim 1336$ | 256 | **64** | **$20.9\times$** |
| $768 \times 768$ | $\sim 3010$ | **576** | **144** | **$20.9\times$** |
| $1024 \times 1024$ | $\sim 5350$ | 1024 | **256** | **$20.9\times$** |
| $1536 \times 1536$ | $\sim 12040$ | 2304 | **576** | **$20.9\times$** |
| $2048 \times 2048$ ($2\times 2$ AnyRes, tile=$1024$) | - | - | **1280** ($4 \times 256 + 256$ thumbnail) | - |
